    Angular-specific file type classification. Enables context-aware analysis and transformation recommendations.

    Example

    - component: .component.ts files with `@Component` decorator
    - service: .service.ts files with `@Injectable` decorator
    - module: .module.ts files with `@NgModule` decorator
    - directive: .directive.ts files with `@Directive` decorator
    - pipe: .pipe.ts files with `@Pipe` decorator
    - guard: .guard.ts files implementing CanActivate, etc.
    - interceptor: HTTP interceptors implementing HttpInterceptor
    - resolver: Route resolvers implementing Resolve interface
    - model: Data models and interfaces (no Angular decorators)
    - util: Utility functions and helper modules
    - config: Configuration files (environment, app config)
    - test: Test files (.spec.ts, .test.ts)
    - other: Files that don't match known patterns
