    Function planServiceBagSplit

    • planServiceBagSplit(
          cls: ClassDeclaration,
          assignments?: Readonly<Record<string, string>>,
      ): ServiceBagPlan

      The service bag verdict and split plan of a class, the one definition of architecture:service-bag and the service bag transform.

      Data access is decided by checker-resolved calls only (backendCall: HttpClient, NgRx Store reads, httpResource, resource, rxResource; serviceCall: one hop into another class); calls of the class's own methods are followed without limit. Translation, Store.dispatch and storage are no data access. The area of a call is the first segment of its resolved URL (api resolveUrlTemplate); related areas merge (relatedAreas: by URL resource stem). Store and resource reads have no area.

      Verdict: at least SERVICE_BAG_MIN_AREAS areas with at least SERVICE_BAG_AREA_MIN_METHODS data-access public instance methods each. Then each such area is a group; public mappers and private helpers follow the group whose data methods call them (also through each other); instance methods called from two or more groups form the group SERVICE_BAG_SHARED_KEY (<Class>SharedService), which the other groups inject; it is no backend area and does not count for the verdict. Data methods of a one-method area, without a known area or with calls to several areas follow their caller like helpers, else stay. Statics, delegations (same-named forward to an injected field) and methods without a backend call stay unless a group method calls them; then they follow like helpers, so no method of a group calls a method that stays. assignments (method name to group key, shared included) move public instance methods into the group of that key, a new key makes a new group; they also apply when the class is no bag. Compute the plan once before editing the class: it reads the source as it is.

      Parameters

      • cls: ClassDeclaration

        A class, usually one that passed serviceBagCandidate.

      • assignments: Readonly<Record<string, string>> = {}

        Method name to group key, the user's decisions.

      Returns ServiceBagPlan

      Example

      const plan = planServiceBagSplit(cls);
      if (plan.isBag) {
        plan.groups.filter((g) => 'key' in g).map((g) => g.serviceName); // ['OrdersService', 'MasterDataService']
      }
