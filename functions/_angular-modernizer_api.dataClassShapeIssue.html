    Function dataClassShapeIssue

    • dataClassShapeIssue(classDecl: ClassDeclaration): string | undefined

      Why instances of a class are more than a bag of public properties, or undefined when the class is a plain data class: no base class, no decorator, no constructor code or parameters, no instance method or accessor, no property with a default, a decorator or private, protected or #private access, and no instanceof check against it anywhere in the project. Static members do not count. A typed object literal can stand in for an instance of such a class; whether a given new site can be rewritten (every required property assigned) is the caller's question.

      Used by angular:dto-direct-instantiation (what counts as a DTO) and the dto-object-literal transform (which classes it rewrites), so both apply one definition.

      Parameters

      • classDecl: ClassDeclaration

        Class to inspect; the instanceof search covers every source file of its project.

      Returns string | undefined

      Example

      // export class OrderRow { id!: number; label?: string; }
      dataClassShapeIssue(orderRow); // undefined
      // export class Mapper { map(): void {} }
      dataClassShapeIssue(mapper); // 'the class has a method'
