    Function collectDirectiveIO

    • collectDirectiveIO(
          cls: ClassDeclaration,
          componentDecorators?: readonly string[],
      ): DirectiveIO

      Lists the public inputs and outputs of a component or directive class and its base classes, as a parent template binds them. Members of the class win over same-name members of a base class.

      Parameters

      • cls: ClassDeclaration

        Component or directive class.

      • OptionalcomponentDecorators: readonly string[]

        Project component decorators in addition to Component (parser.componentDecorators) whose metadata can declare inputs / outputs.

      Returns DirectiveIO

      Remarks

      Sources:

      • @Input() / @Output() on properties and accessors, with a string alias or { alias, required }
      • signal APIs: input(), input.required(), model() (input plus <name>Change output), output(), outputFromObservable(), with an { alias } option
      • inputs: [...] / outputs: [...] in the decorator metadata ('prop', 'prop: alias', { name, alias, required })

      Example

      collectDirectiveIO(itemClass);
      // { inputs: [{ name: 'item', property: 'item', required: true, source: 'signal' }],
      //   outputs: [{ name: 'formError', property: 'formError', source: 'decorator' }] }
