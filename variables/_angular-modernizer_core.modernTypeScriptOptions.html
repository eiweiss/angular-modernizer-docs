    Compiler options for strict, modern Angular TypeScript code.

    Each key is a TypeScript compiler option with the value this template recommends. strictTypeScriptOptions lists the strictness flags among them.

    Type Declaration

    • allowSyntheticDefaultImports: boolean

      Allows default imports from modules without a default export.

    • alwaysStrict: boolean

      Emits "use strict" and parses in strict mode.

    • declaration: boolean

      Emits .d.ts files.

    • declarationMap: boolean

      Emits source maps for .d.ts files.

    • emitDecoratorMetadata: boolean

      Emits design-type metadata for decorated declarations.

    • esModuleInterop: boolean

      Emits interop helpers for CommonJS default imports.

    • exactOptionalPropertyTypes: boolean

      Distinguishes optional properties from properties typed undefined.

    • experimentalDecorators: boolean

      Enables legacy decorators as used by Angular.

    • forceConsistentCasingInFileNames: boolean

      Reports imports whose casing differs from the file name.

    • importHelpers: boolean

      Imports emit helpers from tslib instead of inlining them.

    • lib: string[]

      Library declaration files included in the compilation.

    • module: "ES2020"

      Module code generation.

    • moduleResolution: "node"

      Module resolution strategy.

    • noFallthroughCasesInSwitch: boolean

      Reports fallthrough cases in switch statements.

    • noImplicitAny: boolean

      Reports expressions and declarations with an implied any type.

    • noImplicitOverride: boolean

      Requires the override modifier on overriding members.

    • noImplicitReturns: boolean

      Reports code paths in a function that do not return a value.

    • noImplicitThis: boolean

      Reports this expressions with an implied any type.

    • noPropertyAccessFromIndexSignature: boolean

      Requires bracket access for index signature properties.

    • noUncheckedIndexedAccess: boolean

      Adds undefined to the type of index signature accesses.

    • removeComments: boolean

      Keeps comments in the output.

    • resolveJsonModule: boolean

      Allows importing .json files.

    • skipLibCheck: boolean

      Skips type checking of declaration files.

    • sourceMap: boolean

      Emits source maps for JavaScript output.

    • strict: boolean

      Enables all strict type-checking options.

    • strictBindCallApply: boolean

      Checks arguments of bind, call and apply.

    • strictFunctionTypes: boolean

      Checks function parameter types contravariantly.

    • strictNullChecks: boolean

      Treats null and undefined as distinct types.

    • strictPropertyInitialization: boolean

      Requires class properties to be initialized in the constructor.

    • target: "ES2020"

      ECMAScript target version.
