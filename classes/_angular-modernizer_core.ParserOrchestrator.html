    Class ParserOrchestrator

    Parser Orchestrator

    Coordinates parser selection and fallback mechanisms for resilient parsing across different project types. Automatically selects the best parser based on project characteristics and falls back gracefully on failures.

    Architecture:

    ProjectContext → ParserOrchestrator → selectParser() → ParserStrategy
                            ↓
                     [StandardParser, EnhancedParser]
                            ↓
                      Cache (>80% hit rate)

    Selection Algorithm:

    1. Check cache for previous selection
    2. Filter parsers that can handle project (canHandle() == true)
    3. Select parser with highest reliability score
    4. Cache selection for future use
    5. Log decision for feedback system

    Fallback Algorithm:

    1. Try primary parser (from selectParser())
    2. On failure, try each alternative parser in order
    3. Log fallback attempts and results
    4. Throw if all parsers fail

    Example: Basic usage

    import { ParserOrchestrator } from '@angular-modernizer/core';
    import { Project } from 'ts-morph';

    const project = new Project({ tsConfigFilePath: './tsconfig.json' });
    const orchestrator = new ParserOrchestrator(project);

    // Define project context
    const context: ProjectContext = {
      projectRoot: '/path/to/project',
      hasCustomDecorators: true,
      hasPathAliases: true,
      hasComplexConstructors: false,
      angularVersion: '17.0.0'
    };

    // Auto-select best parser
    const parser = await orchestrator.selectParser(context);
    console.info(`Selected: ${parser.name}`); // 'enhanced'

    // Parse with automatic fallback
    const result = await orchestrator.parseWithFallback(
      'src/app/component.ts',
      fileContent,
      context
    );
    console.info(`Parsed by: ${result.parserUsed}`);

    Example: With fallback

    // If primary parser fails, orchestrator tries alternatives
    try {
      const result = await orchestrator.parseWithFallback(file, content, context);
      if (result.fallbackUsed) {
        console.warn(`Primary parser failed, used ${result.parserUsed}`);
        result.failedParsers?.forEach(({ parserName, error }) => {
          console.error(`${parserName}: ${error}`);
        });
      }
    } catch (error) {
      console.error('All parsers failed:', error);
    }

    parseWithFallback

    • parseWithFallback(
          file: string,
          content: string,
          projectContext: ParserProjectContext,
      ): Promise<ParseWithFallbackResult>

      Parse a file with automatic fallback on failure.

      Fallback algorithm:

      1. Try primary parser (from selectParser())
      2. On failure, log error and try each alternative parser
      3. Return first successful parse result with metadata
      4. Throw if all parsers fail

      Resilience: Gracefully degrades to alternative parsers on failure Performance: No overhead unless primary parser fails

      Parameters

      • file: string

        File path to parse

      • content: string

        File content to parse

      • projectContext: ParserProjectContext

        Project characteristics

      Returns Promise<ParseWithFallbackResult>

      Promise resolving to parse result with fallback metadata

      Throws

      Error if all parsers fail

      Example: Successful primary parse

      const result = await orchestrator.parseWithFallback(file, content, context);
      console.info(`Parsed by: ${result.parserUsed}`); // 'enhanced'
      console.info(`Fallback used: ${result.fallbackUsed}`); // false
      console.info(`Errors: ${result.ast.errors.length}`); // 0

      Example: With fallback

      // If EnhancedParser fails, StandardParser used as fallback
      const result = await orchestrator.parseWithFallback(file, content, context);
      if (result.fallbackUsed) {
        console.warn(`Primary parser failed, using ${result.parserUsed}`);
        result.failedParsers?.forEach(({ parserName, error }) => {
          console.error(`${parserName} failed: ${error}`);
        });
      }

    selectParser

    • selectParser(projectContext: ParserProjectContext): Promise<ParserStrategy>

      Select the best parser for the given project context.

      Selection algorithm:

      1. Check cache for previous selection
      2. Filter parsers that can handle the project (canHandle() == true)
      3. Select parser with highest reliability score
      4. Cache selection for future use
      5. Log decision for feedback system

      Performance:

      • Cached selection: <1ms
      • New selection: <5ms
      • Cache hit rate: >80% in typical usage

      Parameters

      • projectContext: ParserProjectContext

        Project characteristics

      Returns Promise<ParserStrategy>

      Promise resolving to selected ParserStrategy

      Throws

      Error if no parser can handle the project

      Example: Standard project (uses StandardParser)

      const context: ProjectContext = {
        projectRoot: '/app',
        hasCustomDecorators: false,
        hasPathAliases: false,
        hasComplexConstructors: false,
        angularVersion: '17.0.0'
      };
      const parser = await orchestrator.selectParser(context);
      console.info(parser.name); // 'standard'
      console.info(parser.getReliability(context)); // 0.95

      Example: Complex project (uses EnhancedParser)

      const context: ProjectContext = {
        projectRoot: '/app',
        hasCustomDecorators: true,
        hasPathAliases: true,
        hasComplexConstructors: false,
        angularVersion: '16.0.0'
      };
      const parser = await orchestrator.selectParser(context);
      console.info(parser.name); // 'enhanced'
      console.info(parser.getReliability(context)); // 0.65
