    Class ImportManager

    Adds, removes and organizes imports in TypeScript source files.

    • ng-morph is used only to add entries to the imports: [] metadata arrays of @Component and @NgModule decorators.
    • ts-morph handles ES import statements: adding, removing, merging, aliases and non-Angular imports.

    addNamedImport

    • addNamedImport(
          sourceFile: SourceFile,
          moduleSpecifier: string,
          namedImport: string,
          alias?: string,
      ): void

      Add a named import to a source file. Handles merging with existing imports from the same module.

      HYBRID APPROACH:

      • Angular imports (@angular/*): Try ng-morph for components/modules
      • Non-Angular/complex: Fall back to ts-morph

      Parameters

      • sourceFile: SourceFile

        The source file to modify

      • moduleSpecifier: string

        The module to import from (e.g., '@angular/common')

      • namedImport: string

        The named import to add (e.g., 'CommonModule')

      • Optionalalias: string

        Optional alias for the import (e.g., 'NgComponent')

      Returns void

      Example

      importManager.addNamedImport(sourceFile, '@angular/common', 'CommonModule');
      // Result: import { CommonModule } from '@angular/common';

      importManager.addNamedImport(sourceFile, '@angular/core', 'Component', 'NgComponent');
      // Result: import { Component as NgComponent } from '@angular/core';

      BEFORE (ts-morph): 30 lines with manual checking AFTER (hybrid): ~20 lines with ng-morph for Angular imports

    removeNamedImport

    • removeNamedImport(
          sourceFile: SourceFile,
          namedImport: string,
          moduleSpecifier?: string,
      ): void

      Remove a named import from a source file. Cleans up empty import declarations after removal.

      HYBRID APPROACH:

      • Always uses ts-morph for removal (simpler than ng-morph)
      • ng-morph doesn't provide significant benefits for removal operations

      Parameters

      • sourceFile: SourceFile

        The source file

      • namedImport: string

        The named import to remove

      • OptionalmoduleSpecifier: string

        Optional module specifier to target specific imports

        Handles:

        • Removing specific named imports from import declarations
        • Cleaning up empty import declarations
        • Preserving other imports from the same module

      Returns void

      Example

      // Before: import { Foo, Bar } from './module';
      importManager.removeNamedImport(sourceFile, 'Bar', './module');
      // After: import { Foo } from './module';
