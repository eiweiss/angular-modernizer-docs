    Class BuildOutputParser

    Parses Angular CLI build output to extract compilation errors, warnings, and statistics.

    Supports multiple Angular CLI versions with version-specific parsing logic:

    • Angular v15+: "Error: src/file.ts:10:5 - error TS2345: Message"
    • Angular v12-14: "ERROR in src/file.ts(10,5): error TS2345: Message"

    Features:

    • Multi-line error support
    • Path normalization (relative → absolute)
    • Build statistics extraction
    • Graceful handling of malformed output
    • Optional debug logging for unrecognized formats

    Example

    // Basic usage
    const parser = new BuildOutputParser('15.0.0');
    const result = parser.parseOutput(angularCliOutput);

    console.info(`Found ${result.errors.length} errors`);
    result.errors.forEach(err => {
      console.error(`${err.file}:${err.line}:${err.column} - ${err.code}: ${err.message}`);
    });

    // With debug logging (useful for diagnosing parsing issues)
    const debugParser = new BuildOutputParser('15.0.0', { debugLogging: true });
    const debugResult = debugParser.parseOutput(angularCliOutput);
    // Malformed error lines will be logged to console.warn
