    Class ImportGraph

    Lazily built value-import graph with incremental Tarjan SCC computation, used for circular dependency detection.

    Files are read through a GraphFileSource (disk or a ts-morph file system) instead of the ts-morph project, so the graph does not depend on which files a scan batch currently has loaded.

    • import type and imports whose specifiers are all type-only are skipped
    • export * from / export { x } from barrels are edges (followed)
    • specifiers resolve through the ModuleResolver (tsconfig paths, relative paths, index probing); targets in .d.ts files are dropped
    • strongly connected components are computed on demand
    • per edge, imported symbols used in DI or decorator metadata are recorded (forwardRef, inject(), constructor parameter types, decorator arguments)

    Parse results are shared across instances and keyed by the file version (see clearImportGraphParseCache).
