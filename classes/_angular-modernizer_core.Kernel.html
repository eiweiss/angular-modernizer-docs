    Class Kernel

    The Kernel - Core infrastructure manager.

    The Kernel is domain-agnostic: it knows nothing about Angular, components or transformations. All domain logic lives in plugins.

    Responsibilities:

    1. Manage the ts-morph Project instance
    2. Load and initialize plugins
    3. Provide file system abstraction
    4. Act as the central registry for plugins

    Example usage:

    const kernel = new Kernel({
      tsConfigPath: './tsconfig.json',
      plugins: [myPlugin],
    });

    await kernel.initialize();

    const project = kernel.getProject();
    const plugin = kernel.getPlugin('my-plugin');

      Parameters

        Incremental analysis options

      Returns Promise<unknown>

      Promise resolving to incremental analysis result

      Throws

      Error if Kernel is not initialized

      Example

      const result = await kernel.analyzeIncremental({
        baseBranch: 'main',
        includeDependents: true,
        parallel: true
      });
