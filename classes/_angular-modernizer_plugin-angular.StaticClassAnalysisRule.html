    Class StaticClassAnalysisRule

    Analysis rule angular:static-class-detection: reports classes with only public static members (methods and readonly properties) that can become module-level functions and constants.

    Skips .d.ts files and classes with Angular decorators, extends, abstract, constructor logic, instance members, mutable static properties, private or protected members, or member names that are not valid identifiers. The same criteria are used by StaticClassTransformRule.
