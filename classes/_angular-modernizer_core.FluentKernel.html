    Class FluentKernel

    Fluent kernel with a chainable, builder-style API for analysis and transformation pipelines on top of an initialized Kernel.

    Each builder call adds a stage; FluentKernel.execute runs them in order.

    Example

    const result = await FluentKernel.create(kernel)
      .analyze(['src/**/*.ts'], rules)
      .filter(v => v.severity === 'high')
      .transform('inheritance-to-composition')
      .buildCheck()
      .execute();

    toObservable

    • toObservable(): Promise<unknown>

      Converts the pipeline to an RxJS Observable for reactive execution. Requires rxjs to be installed as a peer dependency.

      Emits events for:

      • stage-start: When a stage begins execution
      • stage-complete: When a stage completes successfully
      • stage-error: When a stage encounters an error
      • progress: Progress updates during execution
      • complete: Final pipeline result
      • error: Fatal pipeline error

      Returns Promise<unknown>

      Promise<Observable> or throws if RxJS not available

      Throws

      Error if RxJS is not installed

      Throws

      Error if no stages are configured

      Example

      const observable = await FluentKernel.create(kernel)
        .analyze(files, rules)
        .filter(v => v.severity === 'high')
        .toObservable();

      observable
        .pipe(
          tap(event => console.info('Event:', event.type)),
          filter(event => event.type === 'complete')
        )
        .subscribe({
          next: (event) => console.info('Pipeline event:', event),
          error: (err) => console.error('Pipeline failed:', err),
          complete: () => console.info('Pipeline complete')
        });
