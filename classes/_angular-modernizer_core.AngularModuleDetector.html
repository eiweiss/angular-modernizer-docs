    Class AngularModuleDetector

    Angular module detector

    Detects Angular module boundaries and lazy-loading patterns. Uses ts-morph to parse @NgModule decorators and extract metadata. Lazy-loaded modules are identified via RouterModule.forChild patterns.

    Example

    const detector = new AngularModuleDetector(project);
    const module = detector.getModuleForFile('src/app/app.module.ts');
    if (module?.isLazy) {
      console.info('This is a lazy-loaded module');
    }
