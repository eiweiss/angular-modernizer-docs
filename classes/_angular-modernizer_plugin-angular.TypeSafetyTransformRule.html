    Class TypeSafetyTransformRule

    Transform rule angular:type-safety-transform: adds missing type annotations to parameters, return types and class properties; implicit any becomes unknown.

    Runs only when the plugin config sets transformationType: 'type-safety'; skips .d.ts files and delegates to TypeSafetyTransformOrchestrator. Nodes that already have a type annotation are left unchanged, so repeated runs are no-ops.

    Example

    const rule = new TypeSafetyTransformRule();
    const context = ContextFactory.createTransformContext({ sourceFile, project, api });
    const result = await rule.transform(context);

    if (result.modified) {
      console.info('Added missing type annotations');
      console.info(`Changes: ${result.changeCount}`);
    }
