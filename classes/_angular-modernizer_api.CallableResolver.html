    Class CallableResolver

    Resolves callables and their callees in a ts-morph project.

    Maps TypeScript declarations to callables (methods, functions, constructors incl. field initializers, accessors, function-valued properties) and resolves what a callable calls: call expressions via the type checker (name-based fallback), new X(), super(), and property reads/writes that hit a getter/setter.

    Remarks

    Shared by CallGraphBuilder (caller/callee trees for one target) and BootstrapExecutionAnalyzer (everything that runs from bootstrap roots).
