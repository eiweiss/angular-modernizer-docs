    Class StandalonePlugin

    Standalone Migration Plugin

    Remarks

    Migrates Angular applications to the standalone architecture introduced in Angular 14. It implements the Plugin interface and is the entry point the Kernel loads.

    What It Provides

    The plugin currently provides one transformation rule:

    • StandaloneMigrationRule: Migrates components, directives, and pipes

    Architecture

    The plugin follows the "Plugin as Container" pattern:

    • Plugin: Handles discovery and registration (this class)
    • Rules: Handle the plugin protocol (TransformRule, etc.)
    • Orchestrators: Handle the business logic (StandaloneMigrationOrchestrator)

    Usage

    The plugin is typically loaded by the Kernel during initialization:

    // In the Kernel or a plugin loader
    const plugin = new StandalonePlugin();
    await plugin.initialize(kernel);

    const transformRules = plugin.getTransformRules();
    // Use the rules to transform files

    See

    • StandaloneMigrationRule for the transformation rule
    • Plugin for the interface contract
