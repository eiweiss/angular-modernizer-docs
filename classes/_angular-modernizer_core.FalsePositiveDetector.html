    Class FalsePositiveDetector

    False Positive Detector

    Detects and filters false positive syntax errors that occur due to parser limitations with external decorator architectures and complex code patterns.

    Remarks

    Security: Regex patterns are designed to prevent ReDoS attacks. Lines longer than maxLineLength (default: 1000) are skipped to prevent performance degradation.

    Use Cases

    1. Constructor Parameters with "import" keyword

      constructor(private importService: ImportService) {}
      // Parser error: "Import statement missing 'from' clause"
      // Reality: Valid parameter name

    2. Super Calls with "import" variables

      super(importConfig, importHelper);
      // Parser error: "Import statement missing 'from' clause"
      // Reality: Valid variable references

    3. Multiple Decorators

      @ExternalDecorator({ id: 'custom' })
      @Component({ selector: 'app-user' })
      export class UserComponent {}
      // Parser may report decorator syntax errors

    4. Path Aliases in Imports

      import { SharedModule } from '@shared/modules';
      // Parser error: Cannot find module '@shared/modules'
      // Reality: Valid tsconfig.json path alias

    Architecture

    SyntaxErrors[] → FalsePositiveDetector → {genuine, falsePositives}
                            ↓
                     Pattern Registry
                     (5+ built-in patterns)

    Example

    const detector = new FalsePositiveDetector();
    const errors = [/* syntax errors from parser */];
    const fileContent = fs.readFileSync('component.ts', 'utf-8');

    const { genuine, falsePositives } = detector.filterFalsePositives(
      errors,
      fileContent
    );

    console.info(`Filtered ${falsePositives.length} false positives`);
    console.info(`Reporting ${genuine.length} genuine errors`);

    filterFalsePositives

    • filterFalsePositives(
          errors: FalsePositiveSyntaxError[],
          fileContent: string,
      ): FalsePositiveFilterResult

      Filter false positives from an array of syntax errors

      This method processes all errors and separates genuine errors from false positives based on the registered patterns.

      Parameters

      • errors: FalsePositiveSyntaxError[]

        Array of syntax errors to filter

      • fileContent: string

        Complete file content for context

      Returns FalsePositiveFilterResult

      Object containing genuine errors and filtered false positives

      Example

      const result = detector.filterFalsePositives(
        [
          { message: 'Import statement missing', line: 15, column: 5 },
          { message: 'Unexpected token', line: 20, column: 10 }
        ],
        fileContent
      );

      console.info(`Genuine: ${result.genuine.length}`);
      console.info(`False positives: ${result.falsePositives.length}`);
      console.info('Filtered by context:', result.filteredByContext);

        The 1-based line number (reserved for future use)

      Returns FalsePositivePattern | null

      The matched pattern if false positive, null if genuine error

      Security: Lines longer than maxLineLength are skipped to prevent ReDoS attacks.

      Example

      const pattern = detector.isFalsePositive(
        'Import statement missing "from" clause',
        'constructor(private importService: ImportService) {}',
        42
      );
      if (pattern) {
        console.info(`False positive detected: ${pattern.context}`);
      }
