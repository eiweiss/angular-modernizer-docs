    Class CacheCoordinator

    Coordinates between Angular's build cache (.angular/cache) and our analyzer cache (.angular-modernizer/cache).

    IMPORTANT: This class NEVER modifies Angular's cache - it's read-only. Only our analyzer cache is modified.

    CURRENT USAGE:

    • Angular cache detection and size calculation (read-only)
    • Smart cache clearing recommendations
    • Foundation for analyzer cache persistence

    FUTURE ENHANCEMENT:

    • Persist build results across validation runs
    • Skip validation for files with successful cached builds
    • Cache invalidation based on file changes and dependencies
    • Expected performance gain: 20-40% for repeated validations
