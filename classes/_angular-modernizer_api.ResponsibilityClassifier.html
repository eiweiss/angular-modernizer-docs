    Class ResponsibilityClassifier

    Classifies the public methods of a service or static helper class into concerns from typed signals (resolved call receivers, field types, return types, URL templates) and groups them into concerns, backend areas and name domains. Method names only add weak evidence; a name alone never decides. Results are cached per method declaration.

    Model:

    • Reading, writing and mapping the class's own data is one concern, data-access. Its backend areas come from the URL of each HTTP call.
    • Technical concerns (event, cache, authentication, authorization, validation, ui-dom, file, dialog-navigation, notification, report, transformation) count next to it.
    • A method that only forwards to the same-named method of an injected service is delegation and never counts.
    • A method without a signal of at least DEFAULT_THRESHOLDS.method is uncertain and carries its signals as evidence for the caller.

    Example

    const result = api.analysis.responsibilityClassifier.classifyClass(cls);
    if (result.assessment.isBag) {
      console.info(result.concerns.filter((c) => c.counted).map((c) => c.concern));
    }
