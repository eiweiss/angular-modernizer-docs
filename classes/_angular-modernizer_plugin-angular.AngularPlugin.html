    Class AngularPlugin

    Plugin that registers the Angular analysis and transform rules of this package with the kernel.

    Remarks

    AngularPlugin.initialize loads .angular-modernizer.json from the project root: per-rule options under rules are passed to the rules that take a config, and parser.componentDecorators extends the decorator names that mark components (default Component).

    Analysis rules (28)

    • angular:missing-onpush-change-detection (MissingOnPushRule)
    • angular:performance-violation: memory leaks and performance issues
    • angular:lifecycle-hook-violation: improper lifecycle hook usage and missing cleanup
    • angular:template-complexity: complex operations in templates
    • angular:immutable-input-violation: mutation of @Input properties
    • angular:missing-trackby: ngFor without trackBy
    • angular:service-without-injectable: services without @Injectable
    • angular:component-without-selector
    • angular:directive-without-selector
    • angular:pipe-without-name
    • angular:async-pipe-misuse
    • angular:unnecessary-change-detection
    • angular:missing-return-type: methods without return type (skips lifecycle hooks)
    • angular:too-many-inputs
    • plugin-angular:rxjs-optimization (RxJSOptimizationRule)
    • plugin-angular:bundle-size-optimization (BundleSizeOptimizationRule)
    • plugin-angular:data-handling-strategy (DataHandlingStrategyRule)
    • angular:type-safety (TypeSafetyAnalysisRule)
    • angular:any-to-interface (AnyToInterfaceAnalysisRule)
    • angular:untyped-dynamic-component (UntypedDynamicComponentRule)
    • angular:interface-duplication (InterfaceDuplicationAnalysisRule)
    • angular:component-wrapper-instantiation (ComponentWrapperInstantiationRule)
    • angular:dto-direct-instantiation (DtoDirectInstantiationRule)
    • angular:magic-string-selector (MagicStringSelectorRule)
    • angular:static-class-detection (StaticClassAnalysisRule)
    • angular:promise-vs-observable-anti-pattern (PromiseObservableAnalysisRule)
    • angular:presentational-component-violation (PresentationalComponentViolationRule)
    • angular:service-mutable-state: mutable state in services

    Transform rules (25)

    Each transform rule runs only when the plugin config sets the matching transformationType; see AngularPlugin.getTransformRules.
