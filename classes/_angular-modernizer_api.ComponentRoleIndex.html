    Class ComponentRoleIndex

    How the rest of a project uses its components: which component templates use a component by selector, where code creates it (routes, dialogs, createComponent, portals, registries) and which inputs and outputs it offers. Every answer is computed once per class; the template hosts of all components are collected in one pass over the project's templates. Create one index per project and scan; it does not notice later edits.

    Remarks

    Template hosts come from DirectiveIndex (the compiler's selector matching), creation sites from DynamicHostFinder (certain and candidate sites), inputs and outputs from collectDirectiveIO. Test files are neither hosts nor creation sites.

    Example

    const roles = new ComponentRoleIndex(project);
    roles.templateHosts(itemClass).map((c) => c.getName()); // ['ListComponent']
    roles.creationSites(pageClass)[0]?.host.route;          // { path: 'items', ... }
    roles.io(itemClass).inputs.length;                      // 1
