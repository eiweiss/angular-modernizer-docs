    Class ProgressStore

    Singleton store for the progress of streaming operations (deprecated streaming path and get-operation-progress), with TTL-based cleanup: finished operations are deleted after 5 minutes, running ones are marked failed with a timeout event after 10.

    Remarks

    Call setResult(operationId, result) before markComplete(operationId): get-operation-progress returns result only for completed operations that have one.
