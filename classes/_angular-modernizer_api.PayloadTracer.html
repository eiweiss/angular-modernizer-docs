    Class PayloadTracer

    Follows one parameter through its callable (and, up to depth, through the callables it is passed to).

    Typical input is an @Output payload arriving in an event handler: the tracer reports where the value is assigned, passed on, tested, returned or re-emitted. Calls that pass it to another project callable are followed into that callable's parameter.

    Remarks

    Syntactic flow over the ts-morph AST with symbol identity: references are identifiers resolving to the parameter or to a local alias of it (const x = evt, destructuring). Values derived by computation (const y = evt ? 1 : 2) are aliases too; values copied into fields or services are reported as a write and not followed further.
