    Class DynamicResultFollower

    Follows the result of dynamic creation sites to their handlers.

    Answers "where does the result of a component created in code go?" for a creation site of DynamicHostFinder: the handler receiving it and what that handler does with it (PayloadTracer effects), a handler that never reads it (resultUnused), or the callers a returned result is forwarded to. Where none of this applies, a note names the reason.

    Remarks

    Followed from the creation call: the member chain (afterClosed().subscribe), a stored result's uses (the one with a receiver first), a receiver as callback or observer next, firstValueFrom/lastValueFrom and await into a local (PayloadTracer.traceVariable), a creation returned from a switchMap/concatMap/mergeMap/exhaustMap callback to the handler of the outer pipe (via), and a result returned from a named callable to its callers, up to two levels (forwardedTo; a variable in between does not count as a level). Operator callbacks in a pipe(...) of the chain that receive the result (filter(r => ...)) are reported as operators; a result read there is not unused. Test files are skipped among the callers. Read-only.

    Example

    const flow = new DynamicResultFollower(resolver, tracer).follow(site);
    // { handler: { parameter: 'res', effects: [...], via: ['switchMap'] } }
