    Class DirectiveIndex

    Project-wide lookup of Angular components, directives and pipes declared in source files, and matching of template elements against their selectors with the compiler's own SelectorMatcher.

    Remarks

    Built lazily on first use. Only classes in the ts-morph program are indexed; declaration files, node_modules and *.spec.ts / *.test.ts files are skipped. Library components (Angular Material, ngx-*) ship compiled metadata instead of decorators and are therefore unknown here; callers report such elements as unresolved. A class with an unparsable selector is listed but never matches.

    Example

    const index = new DirectiveIndex(project);
    index.match({ tag: 'app-item', attributes: [['appTooltip', '']], bindingNames: ['item'] });
    // [{ className: 'ItemComponent', kind: 'component', selector: 'app-item', ... }]
