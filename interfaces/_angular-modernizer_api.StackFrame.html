    Optionalcandidates

    candidates?: string[]

    Project files sharing the frame's basename when it is ambiguous. The frame stays external (isProjectFile: false) instead of guessing one of them.

    col

    col: number

    1-based column number.

    file

    file: string

    Absolute file path. For browser URL frames, the raw URL string.

    functionName

    functionName: string

    Function or method name. '<anonymous>' when not present.

    isProjectFile

    isProjectFile: boolean

    true when the frame's path starts with projectRoot and does not pass through node_modules.

    line

    line: number

    1-based line number.

    OptionalresolvedFile

    resolvedFile?: string

    Absolute project path the frame was mapped to. Set only when file itself is not that path, i.e. for URL and basename resolution.

    OptionalresolvedFrom

    resolvedFrom?: "url" | "basename"

    How resolvedFile was found: from the URL path or from a unique basename.
