    OptionalcomponentPath

    componentPath?: TemplateMemberStep[]

    Component member chain of the iterable when it is one (items, this.items, data.rows, rows(), items!); absent for pipes, index reads, literals and chains that start at a template variable (an outer loop item, @let, #ref).

    expression: string

    *ngFor attribute value as written (let item of items; trackBy: byId); the @for header for blocks.

    itemName

    itemName: string

    Name of the loop variable.

    iterable

    iterable: string

    Iterated expression as written (items, data.rows()).

    kind

    kind: "for" | "ngFor"

    ngFor for the *ngFor microsyntax, for for an @for block.

    offset

    offset: number

    0-based offset of *ngFor or @for in the template text.

    OptionaltrackBy

    trackBy?: string

    trackBy expression of *ngFor, track expression of @for; absent when *ngFor has none.

    OptionaltrackKind

    trackKind?: TemplateTrackKind

    For @for only: what the block tracks by.
