    definedAt

    definedAt: number[]

    Lines where the form is created (initializer or this.x = ...).

    dynamicOperations

    dynamicOperations: (FormOperation & { path: string })[]

    Operations through a computed key (controls[key].disable() in a loop); * marks the dynamic segment. They may hit any child of that path.

    Type Declaration

    property

    unknownPaths

    unknownPaths: { line: number; op: FormOperationName; path: string }[]

    Operations whose path does not exist in the structure (typos, controls added elsewhere).

    • op: FormOperationName

    • path: string

      Dotted path as targeted by the call.
