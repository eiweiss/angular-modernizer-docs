    arguments

    arguments: DynamicHostArgument[]

    The other arguments of the creation call; empty for property sites.

    Optionalcertainty

    certainty?: "candidate"

    Set on candidates only: reached through a registry with a selector the code does not fix.

    col

    col: number

    1-based column of the creation site.

    component

    component: string

    Class containing the creation site, <module> outside a class.

    OptionalcomponentArgument

    componentArgument?: number

    Index of the argument carrying the component; absent for a property (component: X).

    componentFile

    componentFile: string

    File of the class containing the creation site.

    file

    file: string

    File of the creation site.

    in

    in: string

    Callable containing the site (ListComponent.openConfirm).

    kind

    kind: "dynamic"

    Discriminator against template hosts.

    line

    line: number

    1-based line of the creation site.

    resolution

    resolution: DynamicResolution[]

    Hops from the class reference to the site; ['literal'] for a direct class argument.

    result

    result: DynamicResultUse

    What the caller does with the value the creation call returns.

    Optionalroute

    route?: DynamicRoute

    Route entry for Route.component / Route.loadComponent sites.

    OptionalselectorExpression

    selectorExpression?: string

    Candidates: the selector argument at the registry lookup.

    OptionalselectorLiterals

    selectorLiterals?: string[]

    Candidates: literals that selector can take as far as the code shows (the component's is not among them).

    sink

    sink: string

    Callee at the site: AppDialog.open, new AppDialogRef, MatDialog.open.

    via

    via: string[]

    Project wrappers below the sink, down to the library call: ['MatDialog.open'].
