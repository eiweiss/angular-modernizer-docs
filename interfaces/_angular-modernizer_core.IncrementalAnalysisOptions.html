    OptionaltemplateOnlyFiles

    templateOnlyFiles?: string[]

    getBuildScope only: files of the changed set that changed through their external template alone. They count as changed (the component itself is recompiled) but their dependents are not traversed, because a template edit does not change the component's TypeScript API. List them in forceFiles as well; entries outside the changed set are ignored.
