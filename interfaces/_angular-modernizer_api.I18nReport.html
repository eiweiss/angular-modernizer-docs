    languages

    languages: Record<string, string[]>

    Languages per layer: base (unconditional sources) and each overlay group; layers of apps other than the root are prefixed with <app>:.

    missingTranslations

    missingTranslations: I18nMissingTranslation[]

    Keys missing in some languages of a layer that defines them.

    sources

    sources: I18nSourceSummary[]

    Translation sources found, without their definitions.

    undefinedKeys

    undefinedKeys: { key: string; usages: I18nUsage[] }[]

    Used statically, defined in no source of the usage's app (usages outside an app, e.g. in libraries, look at every source). usages lists those usages only.
