    Interface FileDiff

    Diff information for a single file. Represents all changes to one file in the transformation.

    Example

    {
      path: 'src/app/user/user.component.ts',
      oldPath: 'src/app/user/user.component.ts',
      status: 'modified',
      fileType: 'component',
      hunks: [...],
      metadata: {...},
      summary: {
        additions: 7,
        deletions: 2,
        netChange: 5
      }
    }
    interface FileDiff {
        fileLevelSemantic?: SemanticAnnotation;
        fileType: FileType;
        hunks: DiffHunk[];
        metadata: FileMetadata;
        oldPath?: string;
        path: string;
        status: "modified" | "added" | "deleted" | "renamed";
        summary: { additions: number; deletions: number; netChange: number };
    }

    OptionalfileLevelSemantic

    fileLevelSemantic?: SemanticAnnotation

    Overall semantic annotation for file-level changes. Summarizes the primary transformation performed on this file.

    fileType

    fileType: FileType

    Angular-specific file type classification.

    hunks

    hunks: DiffHunk[]

    Change hunks for this file. Empty array for pure renames with no content changes.

    metadata

    metadata: FileMetadata

    File metadata and statistics.

    OptionaloldPath

    oldPath?: string

    Original file path (for renames). Only different from 'path' when status is 'renamed'.

    path

    path: string

    Current file path (relative to project root).

    status

    status: "modified" | "added" | "deleted" | "renamed"

    File change status.

    • added: New file created
    • modified: Existing file changed
    • deleted: File removed
    • renamed: File moved/renamed (may also have modifications)

    summary

    summary: { additions: number; deletions: number; netChange: number }

    Aggregate statistics for this file.

    Type Declaration

    • additions: number

      Added lines in this file.

    • deletions: number

      Deleted lines in this file.

    • netChange: number

      additions - deletions.
