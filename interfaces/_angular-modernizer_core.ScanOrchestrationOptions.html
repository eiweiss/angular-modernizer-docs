    OptionalautoSelectMode

    autoSelectMode?: boolean

    Enable automatic mode selection based on project complexity, default: true. When enabled, the executor analyzes project metrics (file count, LOC, memory pressure) and automatically chooses between Promise-based and worker thread parallelism.

    Set to false to disable auto-selection and use Promise-based mode by default. If useWorkerThreads is explicitly set (true or false), this option is ignored.
