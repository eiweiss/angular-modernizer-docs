    Interface LineChange

    Single line change in a diff hunk. Represents an atomic addition, deletion, or context line.

    Example

    {
      type: 'addition',
      content: '  imports: [CommonModule, UserService],',
      lineNumber: 12,
      syntaxType: 'PropertyDeclaration',
      semantic: {
        intent: 'add-imports-array',
        description: 'Add imports array for standalone component',
        confidence: 0.98
      }
    }
    interface LineChange {
        content: string;
        indentLevel?: number;
        lineNumber: number;
        semantic?: SemanticAnnotation;
        syntaxType?: SyntaxType;
        type: "context" | "addition" | "deletion";
    }

    Properties

    content

    content: string

    Line content (without +/- prefix). Preserves original whitespace and formatting.

    OptionalindentLevel

    indentLevel?: number

    Indentation level (spaces/tabs count). Useful for structural analysis.

    lineNumber

    lineNumber: number

    Line number in the file. For additions: line number in new version For deletions: line number in old version For context: line number in both versions

    Optionalsemantic

    semantic?: SemanticAnnotation

    Semantic annotation explaining the change purpose. Only present for additions/deletions, not context lines.

    OptionalsyntaxType

    syntaxType?: SyntaxType

    TypeScript syntax type of this line. Enables syntax-aware analysis and filtering.

    type

    type: "context" | "addition" | "deletion"

    Type of line change.

    • addition: New line added (prefix: +)
    • deletion: Line removed (prefix: -)
    • context: Unchanged line for reference (prefix: space)
