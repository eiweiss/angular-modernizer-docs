    Enable parallel execution by default (default: true).

    Optional file system adapter. Defaults to RealFileSystemAdapter for production use. Use InMemoryFileSystemAdapter for testing.

    Optionalplugins

    plugins?: Plugin[]

    Plugins to load and initialize. Plugins are initialized in the order provided.

    resourceLimits?: ResourceLimits

    OptionaltransformationCoordinator

    transformationCoordinator?: TransformationCoordinator

    Transformation coordinator for handling code transformations. If provided, enables transformation capabilities.

    tsConfigPath?: string

    Path to the TypeScript configuration file (tsconfig.json). This is used by ts-morph to understand the project structure.
