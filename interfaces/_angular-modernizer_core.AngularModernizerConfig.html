    Optionallayers

    layers?: LayerConfig[]

    Project-specific layer topology for the architecture:layer-boundary-violation rule.

    Each entry defines a named architectural layer, its import alias, the source directories that belong to it (as glob patterns), and which other layers it is allowed to import from.

    When this section is absent or empty the rule is silently disabled.

    Example

    [
      { "name": "core",     "alias": "@core",     "paths": ["src/app/core/**"],     "canImportFrom": [] },
      { "name": "shared",   "alias": "@shared",   "paths": ["src/app/shared/**"],   "canImportFrom": ["@core"] },
      { "name": "features", "alias": "@features", "paths": ["src/app/features/**"], "canImportFrom": ["@core","@shared"] }
    ]

    OptionallayersSource

    layersSource?: LayersSourceConfig

    External layer topology source (e.g. an arch-validator config.js). Loaded by the architecture plugin via dynamic import() and mapped to LayerConfig. Takes precedence over layers when both are set.

    Example

    { "format": "arch-validator", "path": "tools/arch-validator/config.js" }

    Absolute path to the project root directory. Defaults to process.cwd() if not provided. Useful when MCP server runs in a different directory than the target project.
